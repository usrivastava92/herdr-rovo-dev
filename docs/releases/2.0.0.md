## Herdr desktop support

Version 2.0.0 marks the addition of Herdr desktop support alongside the existing Herdr TUI plugin. It includes the desktop functionality first published in v1.3.0 and its reviewed fixes. The major version is an intentional release milestone, not a removal of TUI compatibility.

### New support

- Herdr desktop (`herdr-app` + `hc`) integration for the current `rovo` CLI on macOS and Linux.
- Event-driven OSC 7501 reporting into the existing desktop agents list: working, blocked on permission, done, and error.
- A standalone desktop installer and uninstaller, with a Rovo launch-menu entry. No custom sidebar mod or TUI `herdr` executable is needed for desktop use.
- An explicit launcher that captures the session's terminal so status reports still arrive when Rovo captures hook stdout. All Rovo arguments pass through unchanged.
- Independent desktop and TUI hooks, so both integrations can coexist without desktop events being attributed to a TUI pane.

### Fixes and safeguards included

- Preserve Rovo's eventual exit code when it handles Ctrl+C and continues running.
- Persist the installation-selected Rovo config path for later desktop menu launches, even when installation-time environment overrides are absent.
- Preserve pre-existing program display fields during uninstall, including values equal to installer defaults; remove only the owned launch command.
- Clear the Rovo status when its session or launcher exits, avoiding a stale badge on the remaining shell.
- Validate and bound status messages, reject malformed saved config, and safely handle paths containing spaces or apostrophes.
- Preserve unrelated Rovo hooks and desktop program entries; create timestamped config backups.

### Compatibility and setup

Existing TUI plugin install commands, actions, reporting, and legacy `acli rovodev run` support remain available. TUI users do not need to migrate. The new desktop path targets only the current `rovo` CLI and does not implicitly use legacy `~/.rovodev` configuration.

For desktop, install `rovo`, `jq`, and Mike Farah `yq` v4, run Rovo once to create its config, then run from a checkout:

```sh
bash bin/install-desktop
```

Launch **Rovo** from the desktop menu, or use the installed wrapper:

```sh
~/.rovo/hooks/herdr-managed-desktop/rovo-herdr-desktop
```

Plain `rovo` does not opt into desktop reporting. Restart sessions after installing hooks. Re-run the installer to refresh an earlier desktop installation or change its selected config. Remove desktop integration with `bash bin/uninstall-desktop`, using the same config/app-home overrides used for installation. Display-only program fields are intentionally retained.

### Dependencies and verification

- CI installs checksum-pinned Mike Farah `yq` **v4.54.3** for installer tests. This is a new CI test dependency, not a runtime dependency upgrade or an automatic upgrade of user-installed tools.
- No other dependency upgrades are included in this release.
- Regression coverage includes install/uninstall preservation, config persistence, terminal delivery, handled Ctrl+C, exit codes, status cleanup, and TUI compatibility. Local regression tests and the v1.3.0 GitHub CI run passed.
- A real `hc` 0.1.21 smoke scenario verified lifecycle reporting using a fixture Rovo executable. Actual Rovo CLI/desktop GUI validation remains outstanding; native Windows is not supported.
